
# FARMY - Farm Management System

## Project Title
A Web Based Farm Management System for Livestock and Health Monitoring.

## Description
FARMY is a browser-based application designed to manage livestock,
animal health, vaccination schedules and visitor records.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

## Modules
1. Dashboard
2. Animal Management
3. Vaccination Management
4. Visitor Management
5. Reports

## Features
- Add and delete animal records
- Track animal health status
- Manage vaccination schedules
- Maintain visitor records
- View dashboard charts
- Print farm reports
- Save data using browser LocalStorage

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Start managing livestock records.

## Storage
The application uses browser LocalStorage.
No backend server or database is currently implemented.
